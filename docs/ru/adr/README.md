# Архитектурные решения

[Английский оригинал](../../en/adr/README.md).

ADR фиксируют архитектурную политику и её последствия. Принятие ADR не подтверждает реализацию, квалификацию в рабочем окружении или выпуск стабильной версии.

## Контракт записи

Сохранять ID, имя файла и дату принятия. Установить Date при переходе в Accepted; сохранить заменённую запись и ссылку на новое решение. Использовать Status, Date, контекст, решение, последствия и источники. Добавить поле квалификации, когда принятие политики и приёмка в рабочем окружении различаются.

Справочная часть содержит факты в настоящем времени со ссылками на исходники. Процедуры формулируются инфинитивами. Оформлять измерения датированными протоколами с точными входными данными; прежний протокол не подтверждает более позднего кандидата.
