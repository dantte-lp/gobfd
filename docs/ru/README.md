## Правила применения

- Требование RFC нормативно; руководство производителя задаёт контракт
  конкретной платформы. Ни один из источников не подтверждает результат
  проверки совместимости с GoBFD.
- Различайте реализацию, локальную проверку, wire-квалификацию и выпуск.
- Выполняйте процедуры только в явно выбранном окружении. Сохраните исходную
  конфигурацию и проверьте указанное конечное состояние.
- Проверяйте приёмку точного кандидата и выбранного профиля развёртывания.
