## Primary-source corrections

- RFC 5882 section 4.3 concerns Graceful Restart. General routing reaction and
  EBGP failure handling belong to sections 4.2 and 10.2, respectively, not the
  gist's section 4.3 attribution for generic GoBGP/bridge convergence.
- H-12 drain behavior maps to RFC 5880 section 6.8.16 and RFC 5882 section 8.
  Dampening/hysteresis maps to RFC 5882 section 3.1, not AdminDown section 3.2.
  Citation correction does not fix H-27's missing retry/expiry reconciliation.
- Overlay review uses RFC 8971 sections 5–6 and RFC 9521 sections 4–5.
  RFC 9468/9747 recommendations and project security policies are not
  unconditional RFC MUST requirements.
- H-28 EOF can leave HAProxy listeners alive with stale state; it does not
  necessarily exit the entire process.
- Go timer/channel reasoning uses Context7 `/golang/go`,
  the [Timer contract](https://pkg.go.dev/time#Timer.Stop),
  [Go select specification](https://go.dev/ref/spec#Select_statements) and
  [os.Root contract](https://pkg.go.dev/os#Root). The toolchain remains exactly
  Go 1.27.0; newer documentation does not authorize an upgrade.
