# Поправки к переводу исторического changelog

Поправка от **2026-10-29** относится к разделу `v0.5.0` от 2026-05-01
в [английском changelog](../../../CHANGELOG.md).
В [русском changelog](../../../CHANGELOG.ru.md) пропущены четыре пункта
Changed, переведённые ниже. Опубликованные разделы сохранены без изменений;
эта запись дополняет перевод, не объявляя исторические версии действующими
зависимостями или принятыми артефактами v1.

## Пропуски v0.5.0

| Пункт английской записи | Историческое содержание |
|:---|:---|
| Закреплённые версии GitHub Actions | Версии checkout, cache, setup, CodeQL, GoReleaser, Trivy, gosec, Codecov, Buf, GitHub Script, SonarQube и artifact actions следовали тегам выпусков upstream. |
| Конфигурация Go-линтера | `golangci-lint` включал 93 проверенных анализатора в конфигурации v2; теги JSON/YAML публичного API и CLI сохраняли формат `snake_case`. |
| Инструменты проверки уязвимостей | Запись задавала `govulncheck v1.3.0` и сохраняла OSV Scanner `v2.3.5`, поскольку `v2.3.6` не использовался через `go run` как версионируемый модуль инструмента. |
| Варианты OCI-выпуска | GoReleaser объявлял варианты Debian `trixie-slim` и Oracle Linux `10-slim` для `linux/amd64` и `linux/arm64`. |

Эти утверждения описывают сохранённую запись о выпуске. Действующие правила
для компилятора, инструментов, анализаторов и контейнеров заданы в
[разработке](../09-development.md) и [развёртывании](../06-deployment.md).
Oracle Linux 10 исключён из OCI-квалификации v1. Поправка не подтверждает
повторную независимую проверку исторических артефактов.

[Английская поправка](../../en/reference/changelog-errata.md) содержит
те же пункты и границы исторической записи.
